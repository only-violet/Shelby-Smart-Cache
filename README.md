# Shelby Smart Cache

Storage that earns only when data is actually used.

## Problem

Traditional storage systems reward nodes for storing data — even if no one uses it.

This leads to:
- Junk data
- Inefficient incentives

## Solution

Shelby introduces a read-based incentive model.

This project demonstrates:
- Data is only valuable when it is READ
- Hot vs Cold storage behavior
- Reward simulation

## Features

- Upload data
- Track reads
- Hot/Cold classification
- Reward calculation
